# Cyber Enterprise Lab Roadmap

## Phase 1 – Core Infrastructure

Goal: Build the foundation of the enterprise environment.

Tasks:
- VMware environment setup
- Virtual networking
- Domain Controller deployment
- Active Directory implementation
- Windows client deployment

---

## Phase 2 – Identity and Administration

Goal: Create a realistic Windows enterprise environment.

Tasks:
- Domain users
- Organizational Units
- Group Policy
- Administrative accounts
- Security baseline configuration

---

## Phase 3 – Network Infrastructure

Goal: Build and secure the enterprise network.

Tasks:
- FortiGate firewall
- Juniper routing/switching
- Network segmentation
- Firewall policies
- Network monitoring

---

## Phase 4 – Security Operations Center

Goal: Create centralized visibility.

Tasks:
- Splunk deployment
- Windows event collection
- Linux log collection
- Firewall logging
- Sysmon deployment

---

## Phase 5 – Purple Team Operations

Goal: Simulate attacks and develop detections.

Tasks:
- MITRE ATT&CK scenarios
- Attack simulation
- Detection engineering
- Alert tuning
- Investigation workflows

---

## Phase 6 – Incident Response

Goal: Practice responding to security events.

Tasks:
- Incident documentation
- Evidence collection
- Timeline creation
- Root cause analysis
- Lessons learned
